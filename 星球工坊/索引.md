# 星球工坊 · 上手说明与索引

**一句话**：把任意词条（敌人变种）写到任意可攻打星球上，并且能把未开启 / 隐藏星球调出来、配好该星球的阵营与任务。

## 三步上手

1. **装插件**：把 `dist/PlanetForge.zip`（在上一层 `dist/` 里）导入 Arsenal → 启用 → Purge → Deploy。首次进游戏时插件会**自己生成一份配置**，默认那套就能用（三颗试验星球 + 图灵 + 天使投资）。
2. **要改配置**：双击 `配置生成器.html` →
   - 左边选**模板星球**（来源，建议每个阵营一个）＋ 它下面的**目标星球**（每颗标"无人星球"或"隐藏星球"）；
   - 上面有**搜索框**（输名字或 id 过滤 272 颗星球），底部有**星图对照**可点开放大；
   - 每颗星球**最多 5 个词条**；
   - 想改现有的配置就点**导入现有 cfg**（读回来继续改；界面表示不了的行会原样保留）；
   - 最后 `下载 planetforge.cfg`。
3. **装上它**：双击 `生成配置.bat`（装默认配方），或把刚下载的 `.cfg`／配方 `.json` **拖到这个 bat 上**——
   它会**自动找到插件真正读取的配置**，**先把原文件备份**（`planetforge.cfg.bak-<时间戳>`），再写入；游戏内约 **2 秒**热重载生效。

**看着日志确认**（`%LOCALAPPDATA%\PlanetForge.log`）：`plugin installed`（加载自证）→ `CFG loaded: N line(s)` → 每颗 `WRITE ok …` → 解锁的 `UNLOCK ok planet=…` → `UNLOCK template in use: …` → `UNLOCK task rows … copied=N of M row(s)` → 结尾 `PLANETFORGE ready: …`。

**常见问题**
- **有任务但没变种** ⇒ 缺该星球的 `planet <id> tag …` 行（解锁管任务、词条要单独写，两层）；
- **有变种但没任务** ⇒ `unlock` 那层没生效（先看日志里的 `skipped … not the viewed planet` 或 `no faction N template captured yet`）；
- **想还原** ⇒ 把配置里那一行删掉（插件会把记录和任务行恢复原样），或用 bat 装回备份文件；
- **别用** 268 / 99 这类特殊槽位。

## 用户要用的

| 文件 | 用途 |
|---|---|
| `生成配置.bat` | **一键装配置**：双击＝**自动用 Downloads 里刚下载的 `planetforge.cfg`**（没有就装默认配方）；把 `.cfg` 或配方 `.json` 拖上去＝装那个。会自动找插件真正读取的 cfg 并**先备份** |
| `配置生成器.html` | **图形生成器**（单文件、双击即开）：可加多个模板星球，每块挂多个目标星球，标"无人/隐藏"，每颗≤5 词条，**带按名字/id 的搜索框**，底部有**星图对照**可点开放大 |
| `地图/星图.png` | **星图对照图**（社区截图，来源 [helldivers.wiki.gg / Galactic_War](https://helldivers.wiki.gg/wiki/Galactic_War)）：三大阵营区域与相对位置；**只作参考**——不随战况更新、不可点选，**找具体星球请用搜索框** |
| `示例配置.cfg` | 生成器内置的默认配方（包内初始配置就是这一套） |
| `使用说明.md` | 装法、语法、日志怎么读、排错 |
| `参考_机制与RVA实测.md` | 机制与偏移的实测记录（含参考实现的反汇编还原） |

## 这个 mod 的工具链

| 文件 | 用途 |
|---|---|
| `tools/cfg_gen.py` | 生成器本体（**ASCII 文件名是有意的**：`生成配置.bat` 要用它；给用户看的名字是 `配置生成器.html`）。CLI：`--install` / `--install-file` / `--spec` / `--report` / `--live` / **`--import`（读回现有 cfg）** / `--save-spec` / `--self-test` / `--emit-html` / `--list-planets` / `--list-tags` |
| `tools/配置生成器模板.html` | 图形生成器的页面模板（`--emit-html` 用它产出 `配置生成器.html`） |
| `tools/对齐检查.py` | **插件 ↔ 生成器口径对齐**检查（版本/路径/首行规则/5 条目上限/禁名单/行形状/关键字/词条字典），并产出 `build/generated_default.cfg` 供仿真喂进真解析器 |
| `sim/仿真.lua` | 离线仿真（假 ffi + 假内存），覆盖解析、写入、回滚、模板副本、防串味、生成器产物被真解析器接受等 |
| `build/` | 中间产物（`generated_default.cfg`、仿真用的 cfg/日志） |

## live 导出（游戏里自动生成，生成器可导入）

插件每轮会**只读**导出当前版本的星球表与 tag 哈希表到
`%LOCALAPPDATA%\PlanetForge.live.json`（配置里 `live off` 可关，关掉不影响任何写入）。
生成器 `--live` 会导入它：**新星球会自动出现在可选列表**，**tag 哈希与记录的 32 条不一致会明确报警**
（以后游戏加词条/改词条时，这一步保证我们不会按旧名字瞎用）。
